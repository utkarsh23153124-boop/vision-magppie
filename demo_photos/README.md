# Friends demo photos

Create one folder per friend under `demo_photos`, named with their display name.
Portrait folders are deliberately excluded from the public repository.
Put 3–5 clear portraits per friend inside their own folder (1 photo minimum).

Example: demo_photos/Rahul/front.jpg, slight_left.jpg, slight_right.jpg.

- Ask each friend's permission for this recognition demo.
- One face per photo; no sunglasses, filters or group photos.
- JPEG, PNG or WebP; maximum 5 MB per photo and 5 photos per person.
- Empty folders are ignored. Names starting with _ or . are ignored.
- Original photos stay here until you remove them. The app does not upload them
  to a cloud service. Imported face templates exist in memory until server exit.
- After adding/changing photos: Stop demo, check consent and press Import photos.
- If any photo is rejected, fix it and import again; the previous gallery stays unchanged.
