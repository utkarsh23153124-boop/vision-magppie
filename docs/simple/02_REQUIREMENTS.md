# Build start karne ke liye requirements

- [ ] Camera + DVR/NVR ka brand/model.
- [ ] Entrance camera ka sample view: door aur andar/bahar movement visible ho. Full showroom layout nahi chahiye.
- [ ] 20–30 minutes ki original sample footage with entries, exits, groups aur staff.
- [ ] Central server ka OS/CPU/RAM aur camera tak private network route confirm karna; sab cameras ke saath performance test karna.
- [ ] Camera connection aur installation ke liye IT/installer support.
- [ ] Actual visitors/groups verify karne ke liye ek showroom staff member.
- [ ] Pilot budget aur expected deadline.


Baad mein: showroom label/timings for reports, authorised staff enrolment, staff list/showroom assignments aur dashboard user list. Name/city prototype start karne ke liye mandatory nahi.

Passwords chat mein share nahi karne; setup ke time securely configure karenge.
